# EduForge — перечень офферов: что можно абузить и что надо

Комбайн закрывает **шаг загрузки документа** в SheerID для любого оффера, который проверяет студенческий/учительский статус через SheerID. Ты приносишь живой `verificationId` из виджета вендора — движок проходит `info → SSO → docUpload → S3 → complete` и опрашивает статус.

> **Железное правило:** `verificationId` нельзя сгенерить самому (`POST /rest/v2/verification` → `401 invalidApiToken` у вендоров с API Access Control). Сессию создаёт только бэкенд вендора. Комбайн подхватывает уже открытую заявку.

| **Spotify Premium Student** | $6.99/мес вместо $12.99, Hulu в комплекте | SheerID-верификация студента | Жив |
| **YouTube Premium Student** | ~$7.99/мес вместо $13.99 | SheerID-верификация, ежегодное подтверждение | Жив |
| **Perplexity Education (Pro)** | $10/мес вместо $20 (−50%) | SheerID-верификация студента | Жив |
| **ChatGPT for Teachers (K12)** | Бесплатно до июня 2028 | **Школьный email-домен** (гейт ДО SheerID) + верификация учителя | Жив, но нужен реальный K12-домен |

**Kiro — лучший вход без карты.** Флоу: `kiro.dev/students` → войти edu-почтой (Google/GitHub/AWS Builder ID) → баннер «You are eligible for Kiro Students» → Verify → SheerID-виджет → снять `verificationId` → в комбайн. Верификация разовая (одна попытка на аккаунт). Кредиты не сгорают в плюс, через год даунгрейд до free.

## Tier 2 — живой оффер, но финальный гейт не верификация

| Оффер | Профит | Реальный блокер | Роль комбайна |
|-------|--------|-----------------|---------------|
| **Google AI Pro Student (Gemini)** | 12 мес бесплатно → $19.99/мес | **Карта/PayPal** (Play-касса, SheerID для Pro не спрашивается) | Не нужен — там нет шага документа |
| **Google AI Plus Student** | Скидка/триал | SheerID + карта при активации | Проходит шаг документа |
| **GitHub Student Developer Pack** | Пак тулов, хостинг, кредиты | **Своя проверка GitHub, НЕ SheerID** (форма `/settings/education/benefits`, флаг аккаунта, ALLOWLISTED-домен, камера, гео) | Только генератор документа/расписания |
| **Internshala → Google AI Plus** | 12 мес за ₹0 (Индия) | Индийский регион + карта | Партнёрский лендинг, SheerID может не быть |

> Плата — финальный гейт: верификация лишь разблокирует кнопку, дальше вендор требует платёжный метод своей страны. Без карты пайплайн доходит до checkout и умирает там.

## Tier 3 — типовые SheerID-офферы (programId снимать живьём в вендорском флоу)

Эти вендоры исторически проверяют статус через SheerID. Комбайн работает с любым из них, если снять `verificationId` из их виджета. Живость programId и точные условия проверять на странице оффера перед прогоном.

- **Adobe Creative Cloud** — студенческая скидка (~60%)
- **Apple Music Student** — $5.99/мес + Apple TV+
- **Amazon Prime Student** — триал, затем −50%
- **Hulu Student** — $2.99/мес
- **Tidal Student** — скидка
- **JetBrains** — бесплатный All Products Pack для студентов
- **Notion Education** — бесплатный Plus
- **Figma Education** — бесплатный Professional
- **AutoDesk Education** — бесплатный софт
- **Microsoft Azure for Students** — $100 кредитов без карты
- **AWS Educate / GitHub Campus** — образовательные кредиты

## Что надо для любого прогона (чек-лист)

1. **Живой `verificationId`** (24 hex) из виджета вендора — комбайн его не минтит.
2. **Программа** в комбайне должна совпадать с оффером вендора (`student`, `teachers`, `veterans`, `generic`).
3. **Школьный email-домен** — для гейтов ДО SheerID (Kiro, ChatGPT Teachers, JetBrains, GitHub). Без реального домена заявка не откроется.
4. **Карта/регион** — для офферов с платёжным гейтом (Google AI Pro). Комбайн доводит до документа, платёж — отдельный шаг.
5. **Резидентный прокси** нужной страны — SheerID режет датацентровые IP; гео считается по реальному IP сокета (X-Forwarded-For не работает).
6. **Дата в документе текущая** — генераторы считают семестр/год от `now()`, просроченный документ = мгновенный отказ.

## Где что в комбайне

- Живые programId: `server/config.py → PROGRAMS` (+ таблица в дашборде «Программы»).
- Мёртвые: `PROGRAMS_DEAD`.
- Школы: `SCHOOLS` (4 кампуса Penn State) — расширяемо.
- Типы документов: `DOC_TYPES` (student_id, transcript, teacher_badge, teacher_pdf, teacher_png, psu_card).
- Полный флоу и API: [GUIDE.md](../GUIDE.md).
